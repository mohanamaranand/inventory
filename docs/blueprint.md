# **App Name**: StockPilot

## Core Features:

- Automated S.No Generation: Automatically generate a unique serial number for each inventory item to ensure proper tracking.
- Inventory Item Capture: Capture details for each inventory item, including purchase invoice number, vendor name, date, item STD code, item category, product name, product details, quantity, storage location, and unit price.
- Item Status Management: Update the status of each item, to one of: 'In Stock', 'Assembled', 'Sold as Spare', 'Sold as vehicle', 'Damaged', 'Own use', 'Missing', 'Fault', or 'Returned'.
- Sales Invoice Association: Associate sales invoice numbers with inventory items to track sales and inventory depletion.
- Intelligent Restock Suggestions: Leverage AI to analyze inventory trends and provide suggestions for restocking items before they run out.
- Reporting and Analytics Dashboard: Tool powered by generative AI that provides insights into stock levels, popular items, and potential discrepancies to identify improvements.

## Style Guidelines:

- Primary color: Deep teal (#008080) to convey trustworthiness.
- Background color: Light cyan (#E0FFFF), providing a calming backdrop that reinforces ease of use.
- Accent color: Sea green (#2E8B57), a lighter color creating contrast on main UI elements.
- Body and headline font: 'Inter', a sans-serif with a neutral, objective feel for ease of reading and data presentation.
- Use clean, modern icons to represent different inventory categories and actions.
- Employ a grid-based layout for a structured and easy-to-navigate interface.
- Subtle transitions when updating item statuses or adding new inventory items.
